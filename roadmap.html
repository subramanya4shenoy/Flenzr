    Release sequence & definition of done

    What we ship first, and what does not block the pilot.

    ›

    1 · Creator/brand pilot: secure accounts, persistent media kits/packages, real enquiries and an owner-scoped inbox. Production checks in P13 apply before exposure.

    2 · Web v1: discovery, campaign responses, agreed proposals, deliverables, reviews and notifications.

    3 · Paid collaborations: provider-supported settlement, ledger, webhooks, payouts, refunds and reconciliation. Do not imply escrow/funding before it is real.

    4 · Growth & native: optional AI, advanced branding, subscriptions and iOS/Android after stable web APIs.

    Done means: saved backend state where required, correct permissions, honest empty/error states, responsive UX and meaningful acceptance checks. Current “Done” seeds are development implementation evidence, not production certification.

    Progress math: fully done features / all non-deferred features, equally counted. Partial is not counted as done. This is a scope checklist, not an estimate of effort or delivery dates. Numbered execution subtasks are tracked separately and do not add to this feature total.
